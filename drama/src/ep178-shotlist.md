# 《股路不归》第 178 集｜會見（18 鏡 / 180 秒 / 全劇唯一純對話場）

> 位置：第六篇〈黑箱高頻〉倒數第三集。
> 功能：**兩頁紙，一場戲，把 180 集的主題全部收在這裡。**
> 場景：看守所會見室。一道玻璃、兩支話筒、四十五分鐘。
> 鐵律一：**不用音樂**（全場只有話筒電流聲與呼吸）。
> 鐵律二：**兩個人都不許哭、不許提高音量、不許拍桌。**
> 鐵律三：**凱恩在這場戲裡必須先贏。** 他贏了邏輯，才配當對手。

---

## 一、這一場的設計邏輯（先看，再讀腳本）

**① 這不是「正義戰勝邪惡」，是「兩種資本哲學誰買單」。**
凱恩的每一句話都成立——市場中性、風險自定價、自願進場。他沒有說謊。他輸的不是道理，是證據（第 167 集算法日誌）與代價（陳秀蘭的對帳單）。

**② 王红军全場只做三件事：坐下、貼一張紙、把紙折好。**
他不辯論。唯一的反駁是一個動作。**台詞越少，立場越重。**

**③ 玻璃是第三個角色。**
兩人的臉在玻璃上會重疊——他們是同一種人：都懂人性、都能算計、都下得了手。差別只有一條線：刀朝外，還是朝散戶的養老錢。**一人一副本。**

**④ 英文只在最後出現一次。**
凱恩全程說中文（帶口音），這是他「已經在這裡很久」的證據；只有最後一句切回母語——那是他唯一真心話。

**⑤ 全片唯一那句立場宣言，本場一次都不出現。** 留給第 180 集。這裡只給一張紙。

## 四、演出提示（給演員，不是給 AI）

1. **凱恩不能演壞人。** 他是全片最聰明、最有禮貌、最講道理的人。他說「你會難過，我不會」的時候，語氣應該是**同情**，不是嘲諷。
2. **王红军不能演好人。** 他全場沒有一句為自己辯護。他說「對」的時候，眼睛要看著對方，不能低頭。
3. **兩個人都不許動。** 除了拿話筒、貼紙、折紙、起身，沒有多餘動作。**動得越少，越像真的。**
4. **沉默要給足。** 三次停頓：S06 的 2 秒、S14 的 3 秒、S16 的 1.5 秒。剪輯不能為了趕時間把它們剪掉——這部戲的尊嚴就在這 6.5 秒裡。
5. **玻璃反光必須拍到。** 每隔兩三鏡要有一個「兩張臉疊在玻璃上」的畫面。這是全劇唯一的視覺主題。

## 五、本場設計檢查

| 設計原則 | 本場怎麼做到 |
|---|---|
| 反派先贏 | S05、S07、S13 他的邏輯完全成立，甚至比主角漂亮 |
| 主角回應是動作 | 全場只貼一張紙、折一張紙，一次辯論都沒有 |
| 不喊口號 | 全場沒有出現任何口號；立場由「這張紙上不會再有名字」承擔 |
| 兩種資本哲學對位 | S07 vs S18：同一句話的兩種說法，相隔 117 秒互相回答 |
| 收於不勝 | 他沒有贏。對方掛了電話先走。他一個人對著忙音說完最後一句 |

## 六、兩個可選版本（給剪輯現場決定）

**版本 A（已寫）：他先走。**
凱恩掛電話、起身、走進暗處。王红军對著忙音說話。**權力在對方手上**——這版更冷，也符合「他没有赢」。

**版本 B：他最後走，但在門口停住。**
王红军走到門口，回頭看一眼空椅子，然後出去。**留一個「他也想再坐一會兒」的餘地**——這版更痛，但會軟化立場。

**建議用 A。** 這部戲不需要安慰觀眾。
