# 【作者定位】閨閣之事（表） · 宮牆之內（裡）

> **紅樓＝紫禁城外牆之紅色**——書名已指宮牆，非尋常人家之樓。表層寫**閨閣之事**（大旨談情，作者自掩之辭），裡層是**宮牆之內**的權力與對話。寫書者是**行走南書房的人**——近臣能入宮庭、聞核心對話；明末清初文人等外人，無從爆出紫禁城的核心對話內容。作者復借第1回石兄與空空道人的對話自述定稿方向：要把《石頭記》**修改為「理學之書」**。

## 中心思想（第76回妙玉續詩）

> **「贔屭朝光透，罘罳曉露屯」**

**不在第1回、不在第5回**（第1回是開卷敘事總綱、第5回是判詞總綱）。

| 層 | 內容 |
|---|---|
| **字面** | **上句「朝光透」寫國運之衰**——朝光漸透，朝廷光華將盡，國步已入頹途；**下句「曉露屯」寫救亡之志**——曉露方屯，閉門自省，思挽狂瀾於既倒，出灰暗而重築家園 |
| **義理** | 化用《岳陽樓記》「先天下之憂而贔屭，後天下之樂而罘罳」——贔屭＝憂、罘罳＝樂 |
| **根柢** | 非士大夫專屬之憂樂觀，乃**君臣之道**——歸於《大學》三綱，綱各領一義：**明明德**（朝光將晦，憂而思明其德）、**親民**（曉露方屯，閉門自省以安民興家）、**止於至善**（挽狂瀾於既倒，重築家園，終止於至善） |

## 與紅學的分野

**非謂紅學無功，乃所治者異**：彼問作者，本站問文本；彼以考據為徑，本站以方言為鑰——各有其明，亦各有其限；兩途不必相非，唯求於書有所得耳。

| 　 | 紅學 | 本站 |
|---|---|---|
| **所問** | 誰寫的？曹家事（作者與家世） | **書中寫的是什麼**（文本義理與歷史對位） |
| **作者** | 曹雪芹（江南織造家文人）——**外人，無從知宮中核心對話** | **行走南書房的人**（近臣）——書中能爆出紫禁城核心對話，正見作者身份 |
| **所憑** | 考據：生平、家世、版本源流 | 版本對勘＋**方言** |
| **所限** | 諸先生皆非廣府人，於廣府白話**未嘗深究**——加密之白話少所解 | 他方言能解多少，**不敢妄斷** |
| **路徑** | 脂批**取以為證據**（指認作者與家世），**未循為路標**（問這一句在說什麼）——**路標在側而未由，讀者之路遂偏** | **以脂批為路標** |

**白話＝方言**：白話是留存在各地的方言；**各方言區的讀者讀書中白話各有能解，所解各異**。廣府白話（含廣府地區農民的土話）比之他方言，**只是能解讀的字義多些**——非謂惟廣府可解。

**路標之例**：「此玉非彼玉，代字有弓弦影」「再出一芹一脂」諸批，本是指人身分的密碼，卻多被讀成作者的簽名。
