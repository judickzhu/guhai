交易前自檢表

  • 恐慌性拋售（恐懼）：暴跌中不計成本割肉 → 自檢「我賣出是因為邏輯變了，還是因為害怕？」→ 暴跌前列好賣出條件；不在恐慌高峰下單
  • 追漲（貪婪）：上漲時怕踏空急買 → 自檢「這價位買入的賠率還划算嗎？」→ 設目標價，不到不追；錯過就錯過
  • 心理較量：想扛到對手先崩潰 → 自檢「我是否在用意志對抗市場？」→ 用紀律（止損）取代意志
  • 情緒操縱：盤面異動引誘追/殺 → 自檢「此刻的衝動是我的，還是被勾出來的？」→ 異動/消息出現時先離場觀望再決定
  • 羊群效應：大家一致看多/看空 → 自檢「我的依據是獨立分析，還是大家的情緒？」→ 大眾極端一致時警惕反轉
  • 錨定效應：死盯千點/成本價 → 自檢「這個點位本身有意義嗎？」→ 以趨勢/均線而非整數關口做決策
  • 損失厭惡：怕割肉、死扛虧損 → 自檢「如果今天空倉，我會買這隻嗎？」→ 預設止損並機械執行
  • 處置效應：急賣盈、死持虧 → 自檢「我賣/留的理由是否與成本有關？」→ 按基本面/趨勢決定，忽略成本
  • 沉沒成本：「都拿這麼久了」 → 自檢「沉沒成本能影響未來嗎？」→ 只評估未來，不問過去投入
  • 專家崇拜：聽信股評/內幕 → 自檢「這人為我的虧損負責嗎？」→ 只信公告＋自己核實
  • 認知失調：虧了還找理由自我安慰 → 自檢「我在找理由，還是在找真相？」→ 寫交易日誌，強制記錄反證
  • 賭徒謬誤：「跌這麼久該漲了」 → 自檢「獨立事件有記憶嗎？」→ 用趨勢確認，不猜底
  • 信息瀑布：傳聞滿天飛 → 自檢「這是公告，還是傳言？」→ 未證實的消息一律不交易
  • 群體極化：群裡越聊越看多 → 自檢「群體情緒是否放大了我的樂觀？」→ 保留反對聲音、獨立覆盤
  • 倖存者偏差：只看到暴富故事 → 自檢「我看不見的輸家在哪？」→ 看失敗案例，估真實勝率
  • 心理帳戶/開戶潮：新資金蜂擁入市 → 自檢「我是否用「不是自己的錢」心態冒險？」→ 只投閒錢、控制倉位
  • 攀比暴富敘事：被「百元變萬元」刺激 → 自檢「我在投資還是在賭暴富？」→ 設定年化預期，拒絕一夜暴富
  • 孤獨與異化：交易成為生活全部 → 自檢「我是否失去生活平衡？」→ 設休市日、保持線下社交
  • 道德衝突：參與灰色操作 → 自檢「這做法合規嗎？」→ 遠離違法操縱，合法投資
  • 死亡焦慮：押上性命/借貸博命 → 自檢「輸光會怎樣？」→ 不借貸不透支，資金安全第一
  • 心理支撐位：迷信整數關口 → 自檢「支撐是心理還是真實買盤？」→ 結合成交量確認，不單純押點位
  • 自我服務偏差：賺了歸己、虧了怪市場 → 自檢「這筆的運氣成分多大？」→ 歸因覆盤，記錄決策當時依據

《股道》紀律自檢

  • 止損：【原書】單筆虧損 ≤ 20%｜【南嗥建議】更嚴：≤ 8% 或跌破關鍵均線
  • 倉位：【原書】紅滿倉／綠空倉／黃半倉｜【南嗥量化】趨勢向上 60-80%、震盪 30-60%、向下 ≤30%
  • 風報比：【南嗥建議】≥ 1:2（盈利空間 ≥ 虧損空間 2 倍）
  • 不追成功率：【原書】容忍 10 次交易 7 次失敗，但單次虧損嚴格受限（小虧大賺）
  • 化繁為簡：【原書】只信公司公告＋盤後 K 線；未證實的消息一律不交易
  • 資金紅線：【南嗥建議】不透支、不借貸、不押身家

平時資金＋時間優勢（5回）只投閒錢、無槓桿、無借貸；預設止損價與賣出條件
暴跌中迅速減倉自保（106回）先減倉自保、不「死扛」；異動／放量急跌先離場觀望，不接飛刀
底部低位大批量接貨（67回）不猜底、不「盲目等待」（39回）；等右側確認（止跌放量＋站回均線）再分批
修復期推高後全身而退（67回）反彈到目標位或破位即離場，不幻想「時間一定修復成本」

黑天鵝應對程序（紀律版 V4）

  1. 減倉自保：衝擊爆發即把倉位降到可承受水平，不「死扛」
  2. 不猜底：不接下跌飛刀；未證實消息一律不交易
  3. 等右側：止跌放量＋站回均線再分批
  4. 時間紅線：不借貸、不透支——「扛得起時間」是散戶唯一能搶回的時間優勢
  5. 覆盤：這筆是自保還是死扛？是否寫下止損價與風報比？
